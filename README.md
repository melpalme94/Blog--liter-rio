📖 Blog Literário — Literatura Universal

Projeto de um site literário com estética clássica, desenvolvido com HTML5 e CSS3, apresentando poemas e poesias da literatura universal.

O design foi construído com foco em:

Tipografia serifada

Fundo claro

Leitura confortável

Estrutura semântica

Responsividade

Separação entre HTML e CSS

✨ Conceito Visual

O layout segue uma linha clássica e editorial, inspirado em publicações literárias impressas.

Tipografias utilizadas:

Playfair Display (títulos)

Lora (corpo do texto)

Ambas importadas via Google Fonts.

🧱 Estrutura HTML

O projeto utiliza estrutura semântica moderna:

<header>

<nav>

<main>

<article>

<footer>

Cada poesia está organizada dentro de uma section com:

<article class="post">
    <h2>Título</h2>
    <p class="autor">Autor</p>
    <p class="poema">
        Texto da poesia
    </p>
</article>


A imagem entre poemas utiliza:

<div class="imagem-central">
    <img src="imagens/imagem-poesia.jpg" alt="Descrição da imagem">
</div>

🎨 Responsividade

O site é totalmente responsivo.

Técnicas aplicadas:

max-width no container principal

margin: auto para centralização

width: 100% + height: auto para imagens

Media query para telas menores que 768px
